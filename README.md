## Project Description
This project is a simple authentication system built using **React (Frontend)** and **Node.js with Express (Backend)**. It uses **JWT (JSON Web Token)** for secure user authentication.

## Features
1. User login authentication  
2. JWT token generation  
3. Protected dashboard route  

## Tech Stack
1. React  
2. Node.js  
3. Express  
4. JWT  
5. Axios
